Each recipe is a complete program. Save it, put your key in `.env`, and run it with `node --env-file=.env file.cjs`
or `npx tsx --env-file=.env file.mts`. Try them on demo first.

your system's scheduler (cron, or Task Scheduler on Windows) is simpler than a program that never stops.
