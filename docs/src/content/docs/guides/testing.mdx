The testing kit lives in its own entry point, `@kkkermit/trading212.js/testing`, so it never ends up in your
production bundle. It works with any test runner; the examples use [Vitest](https://vitest.dev).

## The fake Trading 212

`createFakeTrading212()` returns a real `Trading212` client whose `fetch` is an in-memory Trading 212, so your code
runs exactly as it would against the API: validation, errors, pagination, the live-trading switch and all. There is no
network and no key, and rate limiting is off, so tests run instantly.

<Example name="testing-fake" file="take-profit.test" />

What it does:

- **Market orders fill at once** at the current price, moving cash and positions and writing history.
- **Limit and stop orders wait** until you call `server.fill(orderId, price?)`. Their cash or shares are reserved
  meanwhile.
- **It refuses what Trading 212 refuses:** not enough cash, selling more than is available, more than 4 decimal
  places, `extendedHours` on a non-market order, an unknown ticker, a closed market (`server.marketOpen = false`) and
  the wrong key.
- **History is paginated** with `nextPagePath`, like the real API.
- **CSV exports are refused on demo.** Use `environment: "live"` or `server.exportsOnDemo = true` to test them. It
  checks that your code sends no credentials to the download link.

## Setting up the account

Everything in `state` is optional:

```ts
const { client, server } = createFakeTrading212({
	state: {
		cash: 5000,
		currency: "GBP",
		prices: { AAPL_US_EQ: 200 },
		positions: [{ ticker: "MSFT_US_EQ", quantity: 3, averagePrice: 380, inPies: 1 }],
		dividends: [{ ticker: "MSFT_US_EQ", amount: 2.1, paidOn: "2026-06-12T00:00:00Z" }],
	},
	client: { logger: console }, // any other client option
});
```

Without `instruments`, it offers Apple, Microsoft and Tesla on US markets, and Vanguard's S&P 500 ETF in London
(`DEFAULT_INSTRUMENTS`). A ticker without a price costs 100.

## Changing it during a test

```ts
server.setPrice("AAPL_US_EQ", 250);
server.marketOpen = false; // every order is refused with MarketClosed
server.failNext("placeMarketOrder", { status: 400, body: { code: "MarketClosed" } });
server.failNext("getAccountSummary", { network: "ECONNRESET" });

server.position("AAPL_US_EQ"); // the position as the API would return it, or undefined
server.cash; // free cash
server.requests; // every request the client made, without credentials
```

`failNext()` takes the endpoint's name from [`ENDPOINTS`](/Trading212.js/reference/utilities/#endpoints) and
either a response or `{ network: code }`; queue several to fail several calls. Every control is listed in the
[testing kit reference](/Trading212.js/reference/testing-kit/).

## Testing the live switch

A live fake has trading enabled unless you say otherwise, so you can test what happens when it is off:

```ts
const { client } = createFakeTrading212({ environment: "live", client: { trading: "disabled" } });
await expect(client.orders.buy(order)).rejects.toBeInstanceOf(TradingDisabledError);
```

<Aside>
	The fake does not do currency conversion, fees or partial fills, and its market hours are a simple weekday schedule.
</Aside>

## Scripted fetch

For testing at the HTTP level, `scriptedFetch()` answers from a list, in order, and records every request:

<Example name="testing-scripted" />

A step is a response (`{ status, body, headers }`, all optional), a function that receives the request and returns
one, or an error to throw as a network failure, such as `networkError("ECONNREFUSED")`. `pending()` says how many
steps are left.

## Contract tests against demo

This repository's own `tests/contract` suite runs against the real demo API with `npm run test:demo` when
`T212_DEMO_API_KEY` and `T212_DEMO_API_SECRET` are set, in the shell or in `.env`. It never touches live.
